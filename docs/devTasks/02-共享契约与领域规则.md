# M02 共享契约与领域规则

返回[任务总览](./README.md)。状态：未开始；P0。位置：`packages/contracts`、`packages/domain`。依据：FR 010、FR 020–FR 024、FR 030–FR 033、FR 060–FR 074，需求第九、十一、十二章。

## T03 数据与接口契约

依赖：T01；D01 本地存储边界已确认，照片契约使用本地引用；涉及 D06–D09、D11、D12、D15 的字段定稿仍需确认。

- [ ] 定义六大类别与六维属性；属性顺序固定为探索、勇气、创造、连接、成长、活力，不混淆类别“相遇/学习”与属性“连接/成长”。
- [ ] 按需求第八、十一章覆盖任务正文、最多五步、体验/环境/安全标签、奖励、重复策略、运营版本字段；定义公开字段白名单。
- [ ] 定义 QuestVersion、执行记录、完成记录、流水、奖励领取键、照片引用、操作结果、缓存和事件队列 schemas。
- [ ] 定义 catalog、daily、daily history、事件批量确认及运营接口的请求响应；统一 schemaVersion、revision、UTC 时间与北京时间业务日期。
- [ ] 定义错误 `{ code, message, fieldErrors?, requestId }`，字段无效、权限不足、版本冲突和可重试错误的语义。
- [ ] 给出有效与无效样例、种子数据格式；匿名事件只接受白名单，不接受正文、照片或精确位置。

验收：前后端和导入工具引用同一契约；缺字段、非法枚举、负奖励、错误日期及越界字段均有明确校验结果；D06 确认后验证属性总额和占比，不能直接把需求附录当合法种子。

## T04 领域规则与状态机

依赖：T03；规则相关 D03–D07、D11、D12、D14。

- [ ] 实现纯函数状态转换：收藏独立保存；接取、放弃、重接取、完成、撤销；规定非法转换错误。
- [ ] 定义进行中上限、同任务已有进行中约束及撤销恢复时的数量冲突规则。
- [ ] 定义稳定 questId 普通奖励键、dailyId 每日奖励键、可重复策略；按快照规则计算 XP 和属性，输出可审计的奖励结果。
- [ ] 定义撤销窗口与反向流水结果；重复撤销和撤销后再完成净额正确。
- [ ] 明确等级累计阈值、边界取整和六维归一化；零点数不得出现除零，少于三项任务弱化趋势。
- [ ] 实现发布/安全过滤、会话去重、池耗尽、近期完成策略；时间和随机数由参数传入。
- [ ] 定义今日日期、历史入口和跨日资格规则接口，避免依赖设备默认时区。

验收：状态边界、上限前后、跨版本重复奖励、普通/今日交叉、撤销截止边界、等级阈值前后、空池/单任务池、午夜均有确定用例。规则不导入 React、Dexie 或 Payload。未确认分支不得标为验收完成。

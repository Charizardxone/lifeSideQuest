## T25 内容、实机与上线准备

依赖：T24 通过、D09/D10/D12/D13 确认；内容生产可自 S0 后开始。交付：内容审核/试玩记录、兼容报告、部署手册、备份恢复记录、发布检查表。

### 内容准备

- [ ] 建立内容覆盖矩阵；原型阶段建议 60 条种子，正式首发不少于 120 条，目标 120–180 条；至少 80 条通用可执行作为需求建议目标跟踪。
- [ ] 六类内容均覆盖；时间、预算、同行、环境、风险、奖励完整，所有发布内容完成结构校验和人工安全/体验复核。
- [ ] 修正附录数值不一致后再导入；不能以自动结构校验替代人工审核。
- [ ] 至少 30 条真实内部试玩，记录执行障碍、歧义、安全问题及修改结果。
- [ ] 排好未来至少 14 天今日支线，准备已审核通用替换候选，演练缺排期和紧急替换。

### 兼容、性能与可访问性

- [ ] 真实手机浏览器、微信内置浏览器和主流桌面验证核心闭环；自动 WebKit 测试不替代真实 iPhone 验证。
- [ ] 常规移动网络首屏可交互目标不高于 2.5 秒；记录设备、网络、缓存状态、测量方法与结果。
- [ ] 验证手机竖屏、桌面宽度、44 像素点击区域、键盘焦点、语义标签、对比度、非颜色状态提示和图表文本。
- [ ] 拒绝图片/存储等可选能力时核心路径仍有可理解反馈；记录不支持 PWA 安装的浏览器降级行为。

### 部署与运行维护

- [ ] 根据确认环境部署 HTTPS 静态用户端、Node.js 内容服务、PostgreSQL，核验目标网络可达性和静态路由刷新。
- [ ] 配置允许来源、管理端 Cookie/CSRF、权限、限流、导入限制与日志脱敏；前端构建无服务端密钥。
- [ ] 测试环境演练迁移，生产迁移前备份；记录备份周期、恢复目标、恢复演练结果及应用/数据库兼容回退步骤。
- [ ] 配置 API 错误、事件积压、排期缺口和备份失败告警；按 D09 验证统计留存清理及删除边界。
- [ ] 说明稳定域名的重要性：本地存档按站点来源隔离，服务端备份不包含个人本地照片。
- [ ] 汇总发布检查表、已知限制、验证记录和未解决问题；涉及用户隐私、奖励正确性、权限或关键 AC 的问题未解决不得标记发布完成。

验收：内容数量、人工试玩、未来排期、实机表现、核心测试和恢复演练都有真实证据。本文的编写不代表已执行测试或部署，也不替代实际环境的访问授权。

## T14 完成、撤销与奖励事务

依赖：T04、T06、T12；D03、D04、D06、D14。T16 提供可选记录输入，空记录路径可先开发。

- [ ] 准备稳定 operationId；输入校验、图片处理在事务前完成。
- [ ] 同一事务内校验执行状态和奖励占用，创建 Completion、照片引用、XP/属性流水、RewardClaim，更新 UserQuest，写 outbox 和操作结果。
- [ ] 依据接取快照及规则版本发奖，不读取运营最新奖励覆盖旧接取约定。
- [ ] 相同 operationId 重试返回原结果；不同 operationId 对同一执行记录也不能产生第二个有效完成。
- [ ] 撤销按确认窗口标记原完成失效、追加反向流水、撤回对应有效奖励占用、恢复进行中；保留审计历史。
- [ ] 重复撤销无副作用；再次完成创建新有效记录；统计发送失败不阻止本地完成。
- [ ] 保存失败保持原状态并允许重试，只有提交成功才展示完成反馈。

验收：连续点击、两个标签页、失败后重试均仅一次有效存档和奖励；在事务各写入点注入错误后整体回滚；完成→撤销→再完成净值正确。覆盖零奖励重复任务、跨版本与普通/今日交叉资格，今日集成由 T19 补齐。

## T15 完成反馈与六边形角色卡

依赖：T14；数值 D06。

- [ ] 先确认完成，再展示 XP、六维和等级变化；可立即关闭，并提供查看存档/获取下一条支线入口。
- [ ] 角色卡展示等级、总 XP、有效完成数、最近变化和固定顺序的六维数值。
- [ ] 六边形显示相对分布，配套原始点数和文字列表；少于三项任务显示数据形成中，零数据安全展示。
- [ ] 明确属性表示经历倾向，不使用人格、智力、健康或能力诊断措辞；不做用户比较。
- [ ] 展示聚合可重建，撤销后及时刷新；动效简短并支持减少动态效果偏好。

验收：图表、文本、XP 和完成数与有效记录/流水复算结果一致；等级临界值正确；仅使用键盘、关闭动画或无法看图时仍可理解结果。

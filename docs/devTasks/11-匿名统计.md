- [ ] 增加架构建议的 quest_completion_revoke，关联原 completionId 以计算有效完成；将扩展同步事件契约。
- [ ] 白名单携带 eventId、匿名标识、时间、任务/版本、来源与必要关联 ID；has_note/has_image 为布尔值，不携带正文或图像。
- [ ] 原因限定枚举，来源限定安全类别；不接受任意文本、精确位置或带查询参数的完整 referrer。

## T23 指标查询与运营页面

依赖：T22；D09、D15。

- [ ] 实现 `GET /api/ops/metrics` 与权限受控后台页面，支持日期、任务筛选及曝光、接取、完成、放弃、换出计数。

- [ ] 补充标签维度表现、平均完成耗时及今日参与指标；不把匿名标识数量表述为准确真实人数。

验收：重复、乱序、撤销、跨日、跨周、迟到与零样本数据结果正确；后台筛选与固定样本复算一致；非管理员无法读取统计。标注清数据、多设备和上报失败造成的统计局限。

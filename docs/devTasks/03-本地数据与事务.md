- [ ] 使用 Dexie 定义 LocalProfile、CatalogCache、DailyCache、Favorite、UserQuest、Completion、XpLedger、AttributeLedger、RewardClaim、Photo、Operation、EventOutbox。

- [ ] 首次创建随机本地身份；重启复用同一身份，多标签页初始化不得生成相互覆盖的身份。

- [ ] 保存接取快照与规则版本；收藏独立于执行记录，重接取新建 UserQuest。
- [ ] 提供数据库版本迁移入口、旧版本夹具、升级阻塞和数据库不可用的反馈接口。

验收：持久浏览器上下文关闭重开后身份、执行记录、流水和照片仍存在；历史快照不依赖当前 catalog；升级失败保留旧数据，不自动清库。fake-indexeddb 测试补充真实浏览器验证。

# M05 内容获取与随机

返回[任务总览](./README.md)。状态：未开始；P0。位置：内容端公共 endpoints；用户端 `data`、`features`。依据：FR 001、FR 003、FR 011、FR 012、FR 020–FR 025；AC 01、AC 05、AC 09。

## T10 公开任务目录与缓存刷新

依赖：T05、T08；缓存边界依赖 D02。

- [ ] 实现 `GET /api/public/catalog`，返回 schemaVersion、revision、serverTime、expiresAt、公开任务和下架标识，支持 ETag。
- [ ] 服务端按审核、状态、发布时间及公开安全资格过滤，禁止泄露内部字段。
- [ ] 启动和回到前台时刷新；响应校验通过后原子替换本地缓存，旧响应不得覆盖新 revision。
- [ ] 未修改、无可用任务、首次请求失败、缓存过期分别返回明确状态。
- [ ] 已接取快照独立保留；收藏可标记已下架，不因目录替换丢失个人记录。

验收：新版本和下架可刷新生效；损坏响应、网络失败保留原缓存；有效缓存可回退，过期缓存按确认规则限制新操作。公开 API 不由 Service Worker 再作不可控缓存。

- [ ] 建立 DailyQuest，唯一 `(date, timezone)`，稳定 dailyId 和递增 revision。
- [ ] 排期界面支持查看未来日期、设置已发布审核版本、检测冲突；优先低风险、低预算且多数地区可执行内容。

- [ ] 缺排期触发运营提示；按 D13 统一选用已审核备用方案，不能各客户端自行随机。

# M10 PWA 与可靠性

返回[任务总览](./README.md)。状态：未开始；P0。位置：`apps/web/public`、应用初始化与缓存相关代码。依据：FR 025；需求第十四章的离线、可靠性、性能和兼容要求。

## T20 应用清单、静态缓存与更新

依赖：T01、T05、T11；完整离线验收等待 T21。

- [ ] 配置应用名称、图标、启动地址、显示模式及 HTTPS 条件，支持可用浏览器安装；普通网页核心流程不依赖安装。
- [ ] 使用 vite-plugin-pwa / Workbox 缓存应用外壳和带哈希静态资源，更新完成后清理旧静态缓存。
- [ ] 公开 API 缓存交给应用层；后台、鉴权和事件写接口不得进入 Service Worker 缓存。
- [ ] 新版本提供更新提示，保存当前输入后刷新；静态更新不删除 IndexedDB 个人数据。

验收：已访问用户断网仍能启动应用；安装与普通网页路径均可用；发布新版本后记录/照片保留；管理页面和认证响应不出现在离线缓存。

## T21 离线、迁移与故障恢复

依赖：T20、T10、T16、T19；D02。

- [ ] 验证缓存任务、进行中、存档离线读取与文字完成；联网后内容刷新及事件重试。
- [ ] 分别处理无缓存、缓存过期、日期不确定和目录下架，不用过期内容假装在线推荐。
- [ ] 在真实浏览器验证上一版数据库升级；旧标签页阻塞时提示关闭旧页面，不清库恢复。
- [ ] 处理存储不可用、容量不足和图片写入失败；提供导出、清理照片或移除本次图片再试的入口。
- [ ] 持久化存储申请失败不阻止可用功能，同时明确浏览器数据可能被清理。
- [ ] 验证更新中未保存输入、网络恢复、快速切换前后台；减少首屏依赖和图片加载成本。

验收：短时断网不影响已有记录与文字保存；事务失败无“保存成功”假反馈；升级不丢记录。缓存过期停止新操作的条件以 D02 为准；离线无法即时接收运营下架必须在验收记录说明。

# M01 工程基础

返回[任务总览](./README.md)。任务状态均为未开始；优先级 P0。依据：架构第二、四、十、十一章。拟交付目录：`apps/web`、`apps/content`、`packages/contracts`、`packages/domain`、`tests/e2e`。

## T01 工作区与应用骨架

依赖：无。交付：可分别构建的 React/Vite 用户端和 Payload/Next.js 内容端，共享契约与领域包骨架。

- [ ] 初始化 pnpm workspace；核验兼容版本，固定 Node.js、包管理器和锁文件。
- [ ] 配置严格 TypeScript、两空格缩进、ESLint、Prettier；共享包不依赖 UI 或 CMS。
- [ ] 创建用户端路由与基础布局占位；创建内容端数据库接入骨架，不提前实现业务。
- [ ] 按架构配置 Vitest、fake-indexeddb、Playwright，约定 `*.test.ts` / `*.spec.ts`；提供最小有效启动验证。
- [ ] 在 AGENTS.md 记录实际源码、测试、资源目录及精确命令。

验收：干净环境可安装；两应用与共享包构建和类型检查通过；用户端构建产物不包含服务端依赖或凭证。记录所选版本与运行结果，不能把占位脚本当作测试通过。

## T02 环境、开发命令与 CI

依赖：T01；部署参数涉及 D10。交付：环境模板、本地启动说明、CI 配置及可重复启动的数据库准备步骤。

- [ ] 提供 `.env.example`：服务端数据库地址、Payload secret、站点和允许来源；用户端仅暴露公共 API 地址。
- [ ] 明确 PostgreSQL 创建、迁移、首个管理员初始化及开发数据加载步骤；不设置生产通用默认密码。
- [ ] 实现并验证根命令 `pnpm dev`、`pnpm build`、`pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm test:e2e`、`pnpm db:migrate`；记录前置服务、端口和运行目录。
- [ ] CI 执行格式检查、静态检查、类型检查、单元/集成测试与构建；说明数据库及浏览器测试环境准备方式。
- [ ] 文档列出本地已验证工具与尚缺条件；测试环境使用独立数据，环境文件忽略真实凭证。

验收：另一位开发者按说明能启动两应用；缺配置时错误明确；CI 失败可定位步骤；数据库迁移为显式操作。生产域名未定不阻塞通用开发环境交付。

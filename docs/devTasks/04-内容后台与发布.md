## T08 编辑、审核、发布与下架

依赖：T07；紧急下架规则涉及 D13。

- [ ] 支持新建、编辑、复制、预览；预览使用接近用户端的内容与标签结构。
- [ ] 实现撰写→结构校验→安全复核→体验复核→发布的流程，重要修改重新审核。
- [ ] 发布服务原子生成唯一版本、更新发布指针和目录 revision、写审计；并发发布不产生覆盖。
- [ ] 已发布快照禁止编辑；新编辑生成新版本，前台已接取快照保持原样。
- [ ] 实现 publish/withdraw 自定义接口；下架保存原因、安全提示及目录更新，处理关联未来/当日排期。
- [ ] 支持发布时间生效检查；并发编辑/发布使用 revision 冲突反馈，不能只隐藏按钮。

验收：未审核内容发布失败；编辑新版本不影响旧记录；下架后在线新目录不再推荐该任务。离线生效范围以 D02 为准。直接接口调用不能绕过审核、权限及快照不可变约束。

## T09 任务导入导出

依赖：T07、T03；奖励校验依赖 D06。

- [ ] 选择并文档化 CSV 或 JSON 支持格式，提供模板、样例及格式版本。
- [ ] 支持导入前校验，错误包含行号或条目位置、字段和原因；明确重复 ID 与部分失败的处理策略。
- [ ] 导入只生成/更新允许编辑的草稿，不直接绕过审核发布；限制文件大小和条目数。
- [ ] 按授权范围导出；若提供 CSV，处理单元格公式注入。

验收：合法样例可往返；非法枚举、奖励不合规、重复身份、缺必填字段和超限文件有可定位错误；导入结果不自动公开。内容数量和人工试玩由 T25 验收。

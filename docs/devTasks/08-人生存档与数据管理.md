# M08 人生存档与数据管理

返回[任务总览](./README.md)。状态：主要功能已实现，细项待最终验收（见主要功能闭环验证）；P0。位置：用户端存档/设置 `features`、图片和导出 `services`。依据：FR 004、FR 041–FR 043、FR 045、FR 051；需求隐私最低要求。

## T16 完成记录、照片与存档

依赖：T05、T14；D08、D11、D15 仍待确认。D01 已确认，FR 042 按选择图片、压缩和本地保存实现，不要求登录或云上传。

- [ ] 完成文字和图片均可为空；字数建议 300，确认计数方式及超限提示后统一校验。
- [ ] 一条记录最多一张照片；选择时说明用途，验证实际可解码格式/大小、压缩、本地保存、替换、删除和失败重试。
- [ ] 图片处理失败可移除本次图片后继续；存储失败不能显示成功，正文输入尽量保留。
- [ ] 地点可不填或主动输入城市，不申请精确定位；保存完成时间、快照和实际奖励。
- [ ] 提供倒序列表、类别/时间筛选、缩略图延迟加载、详情和后续编辑。
- [ ] 编辑个人文字/照片不修改任务快照、完成时间或重发奖励；替换删除同步处理无引用图片，防止误删共享引用。
- [ ] 正文按安全文本渲染；后续编辑统计遵守 D15，分析事件不包含内容。

验收：空记录可完成；损坏/超限图片有反馈；断网可写文字；图片删除后正文和奖励仍在；编辑、刷新、重启后数据一致，编辑个人记录不改变完成终态或奖励。

## T17 导出和确认删除

依赖：T16；D01 本地存储边界已确认，D08、D09 仍待确认。

- [ ] 设置页说明当前浏览器/站点存储边界，不提供云备份或自动跨设备恢复，可手动导入持有的 ZIP。
- [ ] 导出带 schemaVersion 的 JSON 与关联照片，保留记录 ID、快照、流水和关联关系，附格式说明；支持用户确认后的替换导入，先预览校验、原子替换个人表、失败回滚、保留公共缓存，见当前使用说明。
- [ ] 从一致的数据快照生成导出，失败可重试；提示导出文件包含私密内容。
- [ ] 删除前明确不可恢复及本地删除范围，用户确认后清除个人表、照片、奖励/操作记录和待发事件，重新生成匿名身份。
- [ ] 删除时协调其他标签页及事件发送，防止旧状态回写；已在途或服务端收到事件按 D09 解释和处理。

验收：有/无图片、空数据导出均可解析，照片与记录关联一致；取消删除没有变化；确认后刷新与其他标签页不恢复旧个人数据；目录缓存的保留策略写明。服务端数据库备份不等于个人数据备份。

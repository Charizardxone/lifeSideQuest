# M06 个人任务管理

返回[任务总览](./README.md)。状态：未开始；P0。位置：用户端 `services`、任务相关 `features`。依据：FR 013、FR 030–FR 033、FR 050–FR 053；AC 02、AC 06。

## T12 收藏、接取、放弃与重接取

依赖：T06、T11；D02、D11、D13、D14。

- [ ] 收藏/移除收藏维护 Favorite，不发放奖励；重复点击不重复创建。
- [ ] 接取在事务内检查任务有效性、同任务进行中记录和数量上限，写接取时间、来源、版本快照及所需 dailyId。
- [ ] 达到上限时引导处理已有任务；建议值 5 须经 D11 确认。
- [ ] 放弃可跳过原因；不扣 XP/属性，无羞辱性文案，自由文本不进入统计。
- [ ] 重接取新建执行记录，保留旧接取时间、状态和历史；普通与今日入口复用同一接取服务。
- [ ] 目录已下架或过期时给出明确不可接取理由；已有执行快照的后续操作遵守 D13。

验收：两标签页在上限附近同时接取不超额；同任务双击接取只有一个进行中实例；放弃不产生奖励流水；重启后状态和快照存在；内容更新不覆盖历史。

## T13 我的支线与空状态

依赖：T12、T11；已完成真实数据联调需 T14/T16。

- [ ] 提供进行中、已完成、想做三个分区；已放弃仅在历史筛选中查看。
- [ ] 进行中展示标题、接取时间、主要标签并链接完成/放弃；已完成展示时间、缩略图、一句记录与存档详情。
- [ ] 想做允许接取和移除，下架时显示不可接取原因。
- [ ] 各分区空状态跳转随机入口或今日支线；数据随本地订阅更新，状态不只靠颜色表达。

验收：收藏、接取、完成、撤销和放弃后分区与数据库一致；空照片/空文字不造成破损布局；另一标签页变更后页面同步。T14/T16 未接入不能标记整个任务完成。

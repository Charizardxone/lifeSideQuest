# 主要功能操作说明

本版已实现用户端核心闭环、内容运营基础及本地统计。按用户确认，首版不做远端统计上报；不能将本版等同于全部生产上线验收完成。

## 启动与地址

```sh
pnpm install --frozen-lockfile
pnpm dev:content
pnpm dev:web
```

当前配置允许的用户端来源是 `http://localhost:5173`，请使用这个地址打开用户端。后台使用 `http://localhost:3000/admin`。如果打开 `127.0.0.1:5173`，需要同步调整 `apps/content/.env` 的 `WEB_ORIGIN`；两种地址属于不同站点存储空间，不共享个人记录。

用户端 `apps/web/.env` 可配置公开的 `VITE_PUBLIC_API_URL`，默认指向本机 3000 端口。不要填入数据库密码或 Payload secret。生产环境两端需使用 HTTPS，并设置精确的用户端允许来源。

已有 PostgreSQL 上已执行 `20260915_125830_main_features`：新增任务、版本、审计、排期与备用设置表；既有运营账号保留为管理员，新建账号默认内容编辑。未清除原表或凭据。

## 发布第一条任务

1. 用已有管理员账号进入后台，现在可看到任务库、已发布版本、今日排期、审计日志和今日备用设置。
2. 在“任务库”新建记录。内容 JSON 预填一个有效草稿模板，包含标题、分类、步骤、体验标签、安全说明及合法基础奖励。按实际任务修改；不能遗漏安全说明或超过五步。
3. 先保存草稿，再提交“待审核”。管理员完成人工安全和体验复核后，勾选对应复核项并保存。
4. 选择“发布”并保存。服务端生成不可变版本；未审核、结构或奖励无效时拒绝发布。
5. 用户端点击“刷新任务库”，即可推荐、浏览、收藏和接取已发布任务。

编辑已发布任务时，先切换草稿再保存修改。旧发布快照继续服务，已接取记录不改变；修改内容会清空复核勾选，重新复核后才能发布新版本。

下架需填写原因。普通下架停止新接取，旧普通执行仍能完成。安全紧急下架被用户端刷新获知后，会自动放弃未结束执行；断网时无法即时获知。下架不能通过切回草稿绕过，必须重新审核发布。

任务模板仅是草稿；应用启动与日常验证不会自动发布生产任务。2026-09-15 已按用户明确授权另行写入并发布 50 条任务，见[首批内容与导入记录](validation/首批50条任务内容与导入.md)。这些任务已做文案、契约和发布检查，不代表经过实地试玩；后续内容仍由运营复核维护。

## JSON 导入导出

后台首页“任务内容工具”提供模板、导出和导入。先选择文件并校验，再确认创建新草稿。最大 1MB / 500 条，整批校验通过才写入，失败回滚；不接受指定 ID 或自动覆盖旧任务，同文件不接受重复标题。

接口（需要运营登录）：

- `GET /api/ops/quests/template`：带 `schemaVersion: 1`、`dryRun: true` 和 `items` 的模板。
- `GET /api/ops/quests/export`：导出可重新导入为新草稿的内容文件。
- `POST /api/ops/quests/import`：默认校验，显式 `dryRun: false` 才创建。
- `POST /api/ops/quests/:id/publish`、`withdraw`：需要管理员和当前 revision；撤下还需 reason，可指定 emergency。

## 今日支线

“今日排期”按北京时间日期选取已审核版本，每天最多一条排期，替换需要原因。日期不能在原记录上更改；换日期请新建。后台“今日备用设置”可指定缺排期时的备用版本，没有合法备用时显示暂无任务。

今日与普通有独立进行中名额，同一个任务可分别接取和完成；按实际完成顺序共用 questId 完成次数。今日每天最多领奖一次，只能当天完成，过期自动放弃、不发奖、不计次。排期替换不覆盖已接取快照或重置领奖次数。往日排期可回顾，不补领奖励。

## 用户端流程

- 首页无需筛选即可随机；同标签页刷新保留本轮看过的集合，全部看完后手动开启新一轮。
- 普通任务同时最多一条，完成或放弃后再接下一条。收藏独立，不发奖励。
- 完成允许空文字、空照片；完成后不可撤销。重复提交不会重复生成存档或奖励。
- 文字最多 300 个可见字符（组合 emoji 算一个）；城市自愿填写，不请求定位。
- 每条存档一张 JPEG / PNG / WebP，原图最多 10MB；本地转为 JPEG，最长边不超过 1920px，压缩到 1MB 内，失败可移除图片继续。照片仅在本机保存。
- 存档支持类别和月份筛选、补记、替换或删除照片；编辑不修改任务快照、完成时间和奖励。成长卡可由流水重算。
- 设置页导出 ZIP，包含带版本的 JSON、照片和本地统计，不提供自动导入恢复。删除需勾选明确确认，清除个人表和本地统计事件，重建身份，保留公共缓存；其他标签页旧身份不能再写回旧数据。
- 设置页进入“本地统计”，按任务与北京时间日期查看推荐、接取、完成、放弃及相关比率。事件不包含文字、照片或城市内容，不向服务端上报；存档补充率按完成时状态统计，后续补记不改变该口径。

## 离线与更新

公共缓存 24 小时有效，过期停止新推荐和接取，已有普通执行和存档仍可使用。今日依旧在北京时间午夜过期。关闭浏览器期间无法执行脚本，重新打开或回到前台时补做过期检查。

生产构建有 PWA 清单和应用外壳缓存，公开 API、后台与认证不进入 Service Worker 缓存。新版本提示先保存输入再刷新，不清理 IndexedDB。开发服务器不安装正式离线缓存，离线验证使用构建后的预览：

```sh
pnpm --filter @sidequest/web build
pnpm --filter @sidequest/web preview --host 127.0.0.1 --port 4173
```

预览如需访问真实内容端，需将 `WEB_ORIGIN` 设为实际预览来源并重启内容服务；自动化页面测试使用隔离的公共目录响应，不改变生产内容。

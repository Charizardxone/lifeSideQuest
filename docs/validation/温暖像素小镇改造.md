# 温暖像素小镇用户端改造

日期：2026-09-16。直接改造现有 React/Vite 用户端，沿用 Payload 公共内容、Dexie、QuestService 与原有奖励算法。涉及 FR 012–013、020–025、030–033、040–045、050–053、070–074 与 AC 01–10 的用户端体验；不代表完整生产验收。

## 后续调整：统一像素小镇

按用户后续要求，已移除简约日常、主题切换入口及 ThemeProvider/偏好监听代码。HTML 启动即固定 `data-theme="pixel"`，旧 `sidequest-theme-v1` 偏好不再读取，不需要清库或改动个人数据。设置中仅显示当前外观说明。下文涉及双主题兼容、切换及原截图的内容为首次改造的历史验证记录。

本次调整通过用户端构建（含 TypeScript 校验）、Lint 和格式检查；相关浏览器回归覆盖旧 daily 偏好、跨标签旧偏好写入、刷新、偏好存储写入受限以及完成存档保留。

## 已实现

- 默认温暖像素小镇；奶油底色、草绿操作、黄昏书店插画、同场景旅人头像、硬阴影与短促按压反馈。Pixelify Sans 仅用于英文短标签、等级与数字，中文正文使用系统字体。尊重减少动态效果，不引入声音。
- 首页自动推荐，标签页 sessionStorage 保存当前公开任务 ID 与既有本轮已见集合。返回、重渲染、刷新不随意换任务；手动换一条/发现下一条才推进，耗尽仍需明确开启新一轮。公共任务更新或下架时不偷偷换成别的任务。
- 推荐、进行中、完成反馈在同一主面板中切换。默认优先普通进行中，今日支线可紧凑切换。手机主操作停靠在导航上方，安全说明提前显示、内容完整保留，长任务可自然滚动阅读。
- 接取前展示步骤、标签、完整安全说明、准备与奖励。任务库移到 `/library`，首页仅保留今日与任务库的次级入口。同步仍由原有启动/前台/联网事件触发，维护操作在设置和错误恢复入口。
- 首页、日志和执行详情直接完成；只有服务事务保存成功才展示奖励。同步提交锁阻止同一事件内连点，服务层幂等和唯一约束继续兜底。失败保留进行中、提示错误、可重试。
- 完成后的文字/照片调用原有 `saveRecord` 编辑相同 completion ID；不改完成时间、快照、流水与奖励。也可跳过表单继续发现。
- 日志默认进行中并可直接完成，完成/想做采用紧凑切换，放弃降为弱化的历史筛选。角色卡合并人物、等级经验、六维图和原始数值，增加最近经历。设置分外观、个人数据、隐私、公共内容。
- 兼容已保存的 daily / pixel 主题值；不迁移、不清库、不重置用户数据。导出、明确确认删除、离线外壳、普通/今日名额和北京时间过期规则继续复用。图片和字体加入 PWA 预缓存。

## “撤销”的规则解释

仓库 AGENTS.md、AC 04 和此前确认均明确“完成不可逆”。本次需求限定“在现有规则允许的时间内撤销”，现有规则没有撤销窗口，因此没有增加撤销完成、奖励回撤或撤销事件。保留并验证的是失败写入的事务回滚；界面继续明确告知完成不可撤销。

| 检查 | 结果 |
|---|---|
| `pnpm typecheck` | 全工作区通过 |
| `pnpm lint` | 通过 |

Chromium 实际验证自动推荐、换一条、返回/刷新稳定、首页接取和完成、普通优先与今日切换、日志直接完成、同事件连续完成只存一条并发一次奖励、文字照片补记、照片删除与压缩、事务失败无成功反馈并可重试、跳过记录继续、持久浏览器重启、离线完成、北京时间午夜过期、主题跨标签同步与偏好存储受限、导出/明确确认删除、空内容与空日志、键盘跳转焦点、减少动态效果与无横向溢出。主按钮位置有视口断言。

浏览器用隔离的公开内容响应和独立浏览器上下文；不会发布测试任务或操作真实个人浏览器数据。内置浏览器插件初始化报 `Importing module "node:process" is not allowed`，因此使用项目既有 Playwright CLI 执行真实 Chromium 并检查生成截图。

本环境浏览器缓存位于 `/tmp/sidequest-playwright`，代理的网段 NO_PROXY 未被测试启动探针识别，实际使用：

```sh
pnpm --filter @sidequest/web preview --host 127.0.0.1 --port 4173
PLAYWRIGHT_BROWSERS_PATH=/tmp/sidequest-playwright NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost pnpm test:e2e --project=chromium
PLAYWRIGHT_BROWSERS_PATH=/tmp/sidequest-playwright NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost pnpm test:e2e --project=webkit
```

常规环境安装方式和命令保持 `pnpm exec playwright install chromium webkit`、`pnpm test:e2e --project=chromium`，未新增应用运行依赖。

- 未验证真实 iPhone/Safari、跨版本 PWA 更新或生产部署；本次不重跑 Payload/PG 生产验收或数据库迁移。真实内容服务需按原工程文档启动，并允许实际用户端来源；首次完全离线且没有任何公共缓存时无法凭空推荐任务，会显示重试入口。

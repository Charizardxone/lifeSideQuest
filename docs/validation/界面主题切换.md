# 界面主题切换

用户确认保留“简约日常”，新增“复古像素 RPG”。入口为设置页的“界面风格”。默认简约日常，不按系统深色设置自动改动用户选择。

## 实现范围

- 两套风格共用页面、路由、任务和奖励逻辑；不复制业务页面，不新增数据库表或服务器接口。
- 简约日常保留原有样式；像素主题使用限定在 `data-theme="pixel"` 下的样式，包含深色点阵背景、方角任务面板、像素风按钮、原创 SVG 风景和分格经验条。
- 中文正文保留系统清晰字体，像素感来自图形、边框和布局；没有远程字体、图片请求、音效或闪烁动画。离线外壳包含主题资源。
- 使用原生单选框，支持键盘选择、焦点显示、即时切换和同源标签页同步。
- 偏好以 `sidequest-theme-v1` 保存在 localStorage，刷新后恢复；未知值回退简约日常。存储不可写时仍可切换，并说明本次选择无法保存。
- 外观设置不属于私人存档，清除个人记录时保留；清理站点全部数据则恢复默认。此边界在设置页明确说明。

## 验证

- 127 项单元/集成测试通过；11 项 Chromium 浏览器测试通过，包括两项新增主题测试。
- 已验证默认主题、切换、刷新记忆、双标签同步、损坏/不可写偏好回退。
- 完成任务后切换主题，经验与存档保持；切回简约后刷新仍正确。
- 手机 375px 宽度下首页和设置页没有横向溢出，已人工检查桌面、手机和角色卡截图。
- 类型检查、ESLint、用户端生产构建通过。仍有此前已记录的依赖注释和大块体积构建警告；本次未完成 WebKit/iPhone 实机验收。

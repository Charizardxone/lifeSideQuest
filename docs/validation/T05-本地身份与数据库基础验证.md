# T05 本地身份与数据库基础验证

## 范围

实现 T05 的独立基础子项，不定义尚未定稿的任务、图片、统计数据表。未触碰 PostgreSQL 或 `.env`。

- 新增固定版本 Dexie 4.4.6，更新依赖与锁文件。
- `apps/web/src/data/database.ts`：`sidequest-local` 数据库 v1，profiles 表固定主键 `local`、唯一 id 索引；显式版本扩展入口，升级阻塞和版本变化反馈，版本变化关闭旧连接。
- `apps/web/src/data/local-profile.ts`：同一读写事务查询或创建 UUID 身份；复用历史身份；无效记录报错但不清库、不覆盖；失败携带原始 cause，不使用临时身份掩盖失败。
- 使用 [Dexie 事务约定](https://dexie.org/docs/Dexie/Dexie.transaction%28%29)，事务中只有 IndexedDB 操作和同步计算，无网络请求。

## 验证

新增 8 项 fake-indexeddb 测试：首次创建与复用、关闭重开、12 次跨连接并发初始化、损坏数据保护、写入失败回滚、已关闭连接错误、升级失败回滚保留旧身份、版本变化关闭旧连接并保留记录。

全量 `pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm format:check`、`git diff --check` 通过；用户端 `pnpm --filter @sidequest/web build` 通过。

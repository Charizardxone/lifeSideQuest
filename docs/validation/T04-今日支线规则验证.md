# T04 今日支线规则验证

## 已确认规则

普通任务最多一条进行中，今日支线独立名额。同一 questId 可跨两个来源同时接取并分别完成，按实际完成先后共用递减次数。今日每个北京时间自然日最多领取一次奖励，只能当天完成，未完成过期自动放弃、不发奖、不增加完成次数。已完成不可撤销。

## 实现与验证

- `getBeijingDate` 使用显式时间参数和 Asia/Shanghai，不依赖设备默认时区。
- `reconcileDailyQuest` 将过期进行中记录转为已放弃，保留终态。
- `assertCanClaimDailyReward` 拒绝非当天完成及同日再次领奖；领取限制按业务日期，不因任务或排期替换重置。
- `assertCanAcceptQuest` 输入限定为普通来源计数，今日规则不读取普通名额。
- 新增 14 项测试，覆盖北京时间午夜毫秒边界、离线后补检查、终态、每天一次、独立名额、共享计数计算示例与非法输入。
- `pnpm test`：6 个文件、100 项测试通过；类型、lint、格式检查通过。

## 边界

这是纯规则层实现，不是实际任务闭环验收。跨来源次数由后续事务服务按 questId 查询，测试中的共享计数为显式输入；真实并发、自动写入过期状态、UI 和每日接取服务尚未实现。浏览器关闭时无法运行，后续服务需在启动、恢复、提交前补做检查，避免过期领奖。运营临时替换已有执行的处理仍待确认。

本记录替代旧单任务验证中“全来源共享名额”和重复奖励验证中“跨来源规则未确认”的现行规则描述；旧测试结果仅代表当时的实现。

## 已发现并修正

- Payload 创建时 originalDoc 可为空对象，不能仅用 truthiness 判断更新；现按原记录 id 判断。
- PostgreSQL JSONB 不保留字段顺序，发布前比较先通过同一契约标准化，避免错误重置审核状态。
- 固定后台 import map 的 TypeScript 输出路径，避免 JS 生成文件被旧 TS 空映射遮蔽。
- 首次 Service Worker 激活使用 clientsClaim 接管当前页，离线重开测试修复后通过。
- 编辑照片保存后清除待上传状态，避免再次保存重复插入同一照片 ID。
- 下架记录不能仅切换为草稿恢复旧公开快照。

## 限制与待验收

浏览器 E2E 使用模拟公共内容，服务端真实 PG 测试单独进行，不等于已完成每个真实 REST 请求的端到端权限验收。当前没有自动发布生产任务。WebKit 本机缺系统依赖，iPhone/PWA 安装和真实升级尚未验收；CI 未远程运行。生产域名、邮件、部署备份与人工内容试玩仍需完成。
